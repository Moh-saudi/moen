# مَعين للتعليم والتطوير المهني

موقع تعريفي بالبرامج التدريبية، وطلبات التسجيل تُرسَل عبر واتساب.
صفحة واحدة `index.html` بدون خطوات بناء (HTML/CSS/JavaScript خالص).

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا بسيطًا:

    python3 -m http.server 8000

ثم افتح http://localhost:8000

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد.
2. من Settings ثم Pages اختر Deploy from a branch، والفرع main، والمجلد root.
3. يعمل الموقع مباشرة لأن التنقل يعتمد على `#` مثل `#/programs`، فلا يحتاج إعادة توجيه.

## أين أعدّل؟
كل الإعدادات والبيانات في أعلى وسم `<script>` داخل `index.html`:

- `siteConfig`: رقم واتساب (`whatsapp`) والبريد (`email`) والمقر والهاتف وروابط التواصل (`social`) وسياسة الإلغاء، وأعضاء اللجنة الاستشارية (`advisors`) والشركاء (`partners`) والخريجين (`graduates`) والصور (`images`).
- `categories`: الأقسام وترتيبها.
- `courses`: الدورات (الاسم والمدة والسعر)، وحالة التسجيل `status` وهي `open` أو `interest` أو `full`، والدفعات `batches`.
- `research`: خدمات الإرشاد البحثي وأسعارها.
- `assets/social`: أيقونات المنصات (رموز مبسطة، استبدلها بالشعارات الرسمية قبل النشر).

## بيانات مطلوبة قبل النشر
- روابط صفحات فيسبوك وإنستغرام ولينكدإن وإكس ويوتيوب وتيك توك.
- المقر والهاتف والشعار.
- أعضاء اللجنة الاستشارية (الاسم والمسمى والسيرة والصورة) والشركاء والخريجون، بموافقتهم.
- مواعيد الدفعات والمحاضرون وطريقة الحضور.
- سياسة الإلغاء والاسترداد وتفاصيل الشهادات.
- وصف ومحاور ومخرجات كل دورة (الحالية نصوص قالبية للمراجعة).
