# مَعين للتعليم والتطوير المهني

موقع عربي وإنجليزي للبرامج التدريبية. تعرض كل صفحة محتواها في HTML جاهز للقراءة، مع روابط واضحة بدل مسارات `#` القديمة. طلبات التسجيل تُحضّر في واتساب ليُرسلها الزائر بنفسه.

## التشغيل والبناء

يتطلب Node.js. من جذر المشروع:

```sh
npm ci
npm run build
```

يمكن معاينة مجلد `dist` بواسطة خادم ملفات ثابت، مثل:

```sh
python -m http.server 8000 --directory dist
```

الموقع العربي يبدأ من `/ar/` والإنجليزي من `/en/`. صفحات البرامج، التخصصات، والدورات لها روابط مستقلة. روابط `#/...` القديمة تُحوّل تلقائيًا إلى الروابط الجديدة عند فتحها في المتصفح.

## النشر والفهرسة

إعداد `vercel.json` يشغّل البناء وينشر `dist`، ويحوّل الجذر إلى `/ar/`. ينتج البناء `sitemap.xml` و`robots.txt` ووسوم canonical وhreflang وبيانات منظمة للمؤسسة والدورات. يُستحسن إضافة النطاق إلى Google Search Console وإرسال رابط خريطة الموقع؛ وجود هذه الملفات لا يضمن الظهور أو الترتيب في نتائج البحث.

## تعديل المحتوى

المحتوى والبيانات وواجهة التطبيق في `index.html`:

- `siteConfig`: بيانات التواصل واللجنة الاستشارية والشركاء والصور.
- `categories`: الأقسام وترتيبها.
- `courses`: الدورات وأسعارها ومددها وحالات التسجيل.
- `research`: خدمات الإرشاد البحثي.
- قاموس `en`: الترجمات الإنجليزية. عند إضافة محتوى عربي جديد، أضف ترجمته هنا قبل النشر.

شغّل `npm run build` بعد أي تعديل للتأكد من توليد جميع الصفحات بنجاح.
